# Iris

A photo library viewer for macOS, inspired by Picasa. Built with Electron, React, and TypeScript.

## Stack

- **Electron 41** — desktop shell
- **React 19** — UI
- **TypeScript 5** — type safety
- **electron-vite 5** — build tooling
- **styled-components** — component styling

## Getting started

```bash
npm install
npm run dev
```

## Scripts

| Command           | Description                                |
| ----------------- | ------------------------------------------ |
| `npm run dev`     | Start the app in development mode with HMR |
| `npm run build`   | Build for production                       |
| `npm run preview` | Preview the production build               |
